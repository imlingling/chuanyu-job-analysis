## 📌 项目概述

在**成渝双城经济圈**建设纵深推进、国家"十五五"规划将"数字经济""人工智能+"列为支柱产业的背景下，川渝对大数据人才的吸纳能力快速上升。然而，作为**专科层次大数据技术专业**的应届生，普遍面临三大求职痛点：

- ❌ **学历门槛高** —— 不清楚专科能投哪些岗位
- ❌ **技能要求模糊** —— 不知道该学什么、先学什么
- ❌ **城市选择盲目** —— 成都 vs 重庆，主战场该选哪

本项目用**可溯源的数据事实**回答一个具体问题：

> **专科生在川渝大数据岗位上，到底有没有机会？机会在哪？该学什么？该去哪？**

## 🎯 核心结论（一句话版）

| 维度 | 结论 |
|------|------|
| **学历** | 专科硬门槛极低——体制内 0 个大专岗、全靠 21 个"不限"岗；企业端明确给出 28 个"大专"坑。主战场应放在市场化公司 |
| **城市** | 重庆核心岗位约是成都的 **17 倍**，且覆盖各区县；成都岗位少而分散 |
| **技能** | 先打牢"一门语言 + 数据库 + 网络"底座，再往网络安全 / AI 应用做差异化，重型框架可后置 |
| **薪资** | 起薪中位数约 **4000 元/月**，合理预期 4k–8k；议价靠项目作品 + 权威证书 |

## 🧩 数据底座（多源异构）

| 数据源 | 类型 | 体量 | 说明 |
|--------|------|------|------|
| 政府公开岗位表 | 体制内真实附件 | **150 条** | 四川/重庆人社局官网《事业单位公开招聘岗位一览表》，可溯源 |
| 中国公共招聘网 | 市场化真实在招 | **5785 条** | 人社部国家级公共就业平台，合规采集 |
| ~~天池公开招聘数据集~~ | ~~疑似合成~~ | ~~5000 条~~ | **弃用**，仅作 Pipeline 方法学验证 |

- **全量清洗集 5328 条**：150 政府 + 5178 市场化，去重清洗后作为川渝公共就业体量基准。
- **深度分析核心集 425 条**：筛出与"大数据/数据分析/数据开发/软件/计算机"强相关岗位（体制内 150 + 市场化 275），作为所有图表与结论的直接对象。

## 🛠️ 技术栈

- **数据采集**：`requests`（纯 HTTP 解析页面内嵌 JSON，无需 Playwright/抓包）
- **数据清洗**：`pandas` + `jieba` + `re`（多源字段对齐、薪资/学历归一、去重、关键词标签）
- **可视化**：`matplotlib` + `wordcloud`（静态图） + `ECharts`（交互看板）
- **前端**：原生 HTML/CSS/JS，暗黑科技风 + 毛玻璃 + `highlight.js` + `mermaid`

## 🔍 合规与伦理声明

- **仅采集公开岗位字段**，主动剔除联系人/电话/地址等个人信息（`aae004/aae005/aae006`）
- **并发 = 1、单请求随机间隔 3–5 秒**，遇 5xx/429 指数退避，不暴力重试
- 仅用于**个人求职研究**，不登录、不绕过反爬、不二次分发原始数据

## ⚠️ 局限性（如实披露）

- **数据偏向体制内**：核心集 425 条中体制内占 150 条（约 35%），政府岗薪资未公开
- **薪资口径偏粗**：样本来自公共就业平台，含大量基层岗，中位数 4000 低于行业感知，不代表 BOSS/猎聘等平台真实市场化薪酬
- **市场化学历标注缺失**：约 197 条市场化岗 JD 未明确学历，学历结论基于已标注子集
- **地域与时段偏差**：重庆样本显著多于成都；数据为 2026 年公开在招快照
