项目背景与数据底座

在成渝地区双城经济圈建设纵深推进、国家"十五五"规划将"数字经济""人工智能+"列为支柱产业培育方向的背景下， 川渝对大数据人才的吸纳能力快速上升。然而，作为专科层次大数据技术专业的应届生， 普遍面临"学历门槛高、技能要求模糊、城市选择盲目"三大求职痛点。

本项目以多源异构真实数据为支撑，构建一条从采集到结论的完整分析链路， 目标是用可溯源的数据事实回答一个具体问题：专科生在川渝大数据岗位上，到底有没有机会、机会在哪、该学什么、该去哪。

  • 全量清洗集 5328 条：由 150 条体制内政府真实岗位 + 5178 条市场化真实在招岗位合并、去重、清洗而成，构成川渝公共就业市场的体量基准。
  • 深度分析核心集 425 条：在上述底座中，筛出与"大数据 / 数据分析 / 数据开发 / 软件 / 计算机"强相关的岗位（体制内 150 + 市场化 275），作为所有图表与结论的直接对象。
设计哲学：把"数据量大"与"结论可信"解耦——5328 条证明工程化处理能力，425 条核心集保证主题聚焦、结论不注水。

DATA COLLECTION

采集 方案

数据源坚持"公开、合规、可溯源"三原则，杜绝任何越权或高并发抓取。

数据甄别实证：立项早期曾评估天池（Tianchi）公开招聘数据集（5000 条），其各维度分布均匀得不符合真实市场规律 （5 档学历各约 20%、15 城每城约 330 条、6 类岗位各约 800 条），提示极可能为模拟 / 合成数据。 结论：弃用该数据集，仅作 Pipeline 方法学验证，真实结论一律由下方两类可溯源数据支撑——这一取舍本身就是数据分析师最核心的素养：来源甄别与结论边界意识。
SOURCE 01 · 体制内真实附件

政府公开岗位表（核心结论支撑）

  • 来源：四川省人社厅人事考试专栏、重庆市人社局官网等公开发布的《事业单位公开招聘岗位条件一览表》。
  • 体量：150 条（四川 75 / 重庆 75），每条可溯源到政府官网原文。
  • 特点：学历、专业要求字段权威；薪资为"按政策执行（未公开）"，体制内不做薪资量化（严谨性，非缺失）。
SOURCE 02 · 市场化真实在招

中国公共招聘网（job.mohrss.gov.cn）

  • 来源：人力资源和社会保障部国家级公共就业平台，川渝两省市全部在招页面。
  • 合规采集：纯 requests 读取列表页内嵌岗位 JSON（无需 Playwright / 抓包）；并发 = 1、单请求随机间隔 3–5 秒、5xx/429 自动退避、主动剔除联系人 / 电话 / 地址等个人信息。
  • 体量：四川 3945 + 重庆 1840 = 5785 条去重真实在招岗位。
  • 诚实约束：该站为综合公共就业平台，纯大数据 / IT 岗约占 5.2%，故 5328 条用作体量基准，425 条核心集作深度分析。

# 薪资标准化：政府岗=未公开(统考)；市场化岗= acb241/242 数值(元/月)
def fmt_salary(mn, mx):
    mn = float(mn) if mn not in (None, "", "nan") else None
    mx = float(mx) if mx not in (None, "", "nan") else None
    if mn and mx:   return f"{int(mn)}-{int(mx)}"
    if mn:          return f"{int(mn)}以上"
    if mx:          return f"≤{int(mx)}"
    return "未公开"

# 学历归一：市场化岗无结构化字段，从 JD 文本启发式抽取；政府岗直接采用权威字段
def derive_edu(text):
    t = text or ""
    if "博士" in t:                       return "博士"
    if "硕士" in t or "研究生" in t:       return "硕士"
    if "本科" in t:                       return "本科"
    if "大专" in t or "专科" in t:        return "大专"
    if "学历不限" in t or "不限学历" in t:  return "不限"
    return "其他"

INSIGHTS & LIMITS

业务 结论

把数据翻译成专科生可执行的求职策略，并坦诚披露分析边界。

01

学历 · 别死磕体制内

体制内 0 个大专硬门槛、专科入口全靠 21 个"不限"岗；企业端明确给出 28 个"大专"坑。重心放市场化公司，体制内仅投"学历不限"岗碰运气。

02

城市 · 主战场选重庆

重庆核心岗位是成都的 17 倍且覆盖各区县；成都岗位少而分散（甚至少于泸州）。把重庆作主战场、成都作实习 / 保底，二线同步关注绵阳、泸州。

03

技能 · 先打底座

先把"一门语言（Python / Java）+ 数据库 + 网络"打牢，再往网络空间安全 / 人工智能应用两个高频方向做差异化，重型框架（Hadoop / Spark）后置。

04

薪资 · 预期务实

起薪中位数约 4000 元 / 月，合理预期 4k–8k。薪资议价靠可演示的项目作品 + 权威证书，而非空谈概念名词。

项目价值：本项目的差异化不在"爬了多少数据"，而在数据来源甄别（弃用合成集）、合规采集（不碰个人信息）、结论边界（真实层 vs 验证层）的方法论自觉——这正是专科生简历最稀缺的"分析师思维"证据。

⚠ 局限性披露（如实披露）

  • 数据偏向体制内：核心集 425 条中体制内占 150 条（约 35%），且政府岗学历字段权威但薪资未公开，导致"体制内薪资"维度缺失。
  • 纯市场化薪资深度不足：薪资样本来自公共招聘网，口径偏粗、且含大量基层岗，中位数 4000 低于行业感知，不能代表 BOSS / 猎聘等平台的真实市场化薪酬。
  • 市场化学历标注缺失：约 197 条市场化岗 JD 未明确学历（归为"其他"），学历门槛结论基于已标注子集，存在低估专科机会的可能。
  • 地域与时段偏差：重庆样本显著多于成都；数据为 2026 年公开在招快照，不反映季节性波动。
